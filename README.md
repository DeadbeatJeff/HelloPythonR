# HelloPythonR
This Hello, World program demonstrates the possibility of running an R application with Python instead of R Shiny. It is just proof-of-concept currently and does not even allow entering a column of data, although that capability and other data processing capabilities will likely be included in future revision.

Quick Start: Download & Run
If you are an engineer looking to use this tool, you do not need to install Python or R. The application is distributed as a self-contained Windows executable.

    * Go to the Releases Page: On the right-hand side of this GitHub repository, click on Releases.
    * Download the Binary: Under the "Assets" section of the latest release, click on main.exe to download it.
    * Run the App: Double-click main.exe.
        * Note: If Windows Defender shows a "SmartScreen" warning, click More Info and then Run Anyway.
    *Calculate: Enter your Z-Score in the UI and click Calculate in R to see the probability results instantly.
